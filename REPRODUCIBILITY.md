# Reproducibility package - Paper A

This directory contains the data snapshot, executable analysis code, frozen CSV outputs, and vector figures used by the CSF submission **What Hawkes branching ratios measure in high-frequency markets: specification sensitivity, mode-resolved bounds and critical slowing down in a Euro–Bund case study** (revision R1).

## Data
`data/bund.npz` is the public Euro-Bund futures tick snapshot distributed with the research workspace (X-DataInitiative/tick-datasets; Bacry-Jaisson-Muzy data lineage). It contains 20 April-2014 sessions and the up/down mid-price and buyer/seller trade event times used in the paper.

## Environment
The original submission was checked with Python 3.13.5 and the package versions in `requirements.txt`. The revision analyses were run with Python 3.12.3 and the versions in `requirements-revision.txt`; the headline full-session medians are identical under both.

## Headline workflow
From this directory:

```bash
python -m pip install -r requirements.txt
python experiments/E1_bund_hawkes.py
python experiments/A_csf_additions.py all --reps 30
python experiments/make_figures.py
```

`E1_bund_hawkes.py` regenerates the core window, moment-estimator and H3' tables. `A_csf_additions.py` regenerates residual-effect sizes, SoE-basis sensitivity, the 30-minute positive B-spline background fits, the known-n multiscale stress map, the bivariate up/down eigenmode fits, and timestamp perturbations. The robustness script is computationally heavier than figure generation; the frozen CSVs used by the manuscript are included in `tables/` and `tables_csf/`.

## Randomness
The controlled stress map and timestamp randomisation use seed `20260914` in the archived code. Optimization itself is deterministic conditional on the data and initialisation implemented in the scripts.

## AI-assisted code development
OpenAI ChatGPT (GPT-5.6 Sol; OpenAI, accessed September 2026) assisted with drafting/refactoring robustness-analysis and plotting code. All reported results were generated by executing Python code against the supplied data, frozen to CSV, and checked against the manuscript tables. Anthropic Claude assisted with drafting the revision analysis code. The author remains responsible for the content.

## Revision analyses (R1)
`experiments/R_revision.py <task>` with tasks `timestamp` (protocols under identical conditions, 100 randomisation draws), `history` (history buffers and boundary exclusion), `nested` (free-rate K = 1, 2, 3, AIC/BIC, held-out likelihood), `bivar` (separate rates, bivariate SoE, mode-implied autocorrelations), `sim` (stationary burn-in, long horizons, correctly specified, off-grid and non-self-exciting controls, multistart), `adeq` (spline and bivariate diagnostics), `boot` and `bootfix` (refitted parametric bootstrap; `bootfix` refits the SoE-truth replications with the well-scaled optimiser), `soecheck` (headline SoE fits at the optimum) and `penalty` (knot x normalised-penalty scan with blocked cross-validation). Outputs are frozen in `tables_rev/`; summaries in `R_summaries*.txt` and `*.json`; figures in `figures_rev/`. Runtime: about three hours on one CPU core.
