# Reproducibility package - Paper A

This directory contains the data snapshot, executable analysis code, frozen CSV outputs, and vector figures used by the CSF submission **What Hawkes branching ratios identify in high-frequency markets: specification uncertainty and critical slowing down in activity**.

## Data
`data/bund.npz` is the public Euro-Bund futures tick snapshot distributed with the research workspace (X-DataInitiative/tick-datasets; Bacry-Jaisson-Muzy data lineage). It contains 20 April-2014 sessions and the up/down mid-price and buyer/seller trade event times used in the paper.

## Environment
The submission was checked with Python 3.13.5 and the package versions in `requirements.txt`.

## Headline workflow
From this directory:

```bash
python -m pip install -r requirements.txt
python experiments/E1_bund_hawkes.py
python experiments/A_csf_additions.py all --reps 30
python experiments/make_figures.py
```

`E1_bund_hawkes.py` regenerates the core window, moment-estimator and H3' tables. `A_csf_additions.py` regenerates residual-effect sizes, SoE-basis sensitivity, the 30-minute positive B-spline background fits, the known-n multiscale stress map, the bivariate up/down eigenmode fits, and timestamp perturbations. The robustness script is computationally heavier than figure generation; the frozen CSVs used by the manuscript are included in `tables/` and `tables_csf/`.

## Frozen headline outputs
- `tables_csf/A_flexible_background.csv`
- `tables_csf/A_soe_sensitivity.csv`

- `tables_csf/A_residual_effects.csv`

The manuscript tables are deterministic summaries of these files. Vector versions of the final figures are included in `figures_csf/`.

## Randomness
The controlled stress map and timestamp randomisation use seed `20260914` in the archived code. Optimization itself is deterministic conditional on the data and initialisation implemented in the scripts.

All reported results were generated by executing Python code against the supplied data, frozen to CSV, and checked against the manuscript tables.
